## Featured project: Campus Calendar Sync

[Code and offline demo](https://github.com/vaishnav26/calendar-sync-agent) | [Product case study](https://github.com/vaishnav26/calendar-sync-agent/blob/main/PRODUCT_CASE_STUDY.md)

A Python and Flask workflow that matches course enrollments to a timetable and syncs classes to Google Calendar. It includes preview before sync, deterministic event IDs, cancellation labels, API retries, caching and daily sync limits. The public copy uses fictional data and includes nine local automated tests.

**Product decisions:** balancing timetable freshness against API quotas, handling repeated syncs, and showing cancellations without unnecessary reminders. The case study documents trade-offs, limitations and proposed success metrics.
